# In-Text Citations → Full References Mapping

This document lists every in-text citation that appears in `Research_Proposal_PPRS_Full.docx`, paired with its full reference entry from the References chapter. Use this when adding **hyperlinks** in Word: select the in-text citation → Insert → Cross-reference → Reference Type "Heading" or "Bookmark" → point at the matching reference.

**Quick instructions for Word:**
1. Open the References chapter in your final docx.
2. Select each reference entry's first author and **Insert → Bookmark** with a memorable name (e.g. `ref_nie_2023`).
3. Go back to the body text; select the in-text citation (e.g. "Nie et al., 2023"); **Insert → Hyperlink → Place in this document → pick the bookmark**.
4. Word will then make the citation clickable; clicking jumps to the reference.

## Step-by-step Word workflow (one-time setup, ~15 minutes for 34 refs)

1. **In the References chapter**, for each entry:
   - Click at the start of the entry (e.g. "Nie, Y. et al. …")
   - **Insert → Bookmark** → type the bookmark name (e.g. `ref_nie_2023`) → Add

2. **In the body of the document**, find every occurrence of that in-text citation using **Ctrl+F**:
   - Search for "Nie et al., 2023"
   - For each occurrence, select just the citation text including parentheses
   - **Insert → Hyperlink → Place in This Document → pick the matching bookmark → OK**

3. **Repeat** for every entry in the table above. Word's "Find" remembers your last search term so you can hit Ctrl+F → Enter → Hyperlink in a tight loop.

4. **Verify**: Ctrl+click any in-text citation; the cursor should jump to the corresponding reference entry.

## Optional: back-links from references to body

For a fully bidirectional bibliography (rare but professional), add a "↩" symbol at the end of each reference entry that hyperlinks back to its first occurrence in the body. Use Bookmark names like `cite_nie_2023_first` on the first body-text occurrence and Hyperlink the "↩" to it.
